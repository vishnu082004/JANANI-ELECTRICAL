# Janani Electricals

React website built with Vite, using the content and media from the Janani Electricals WordPress website.

## Run locally

```sh
npm install
npm run dev
```

## Pages

- `/` — Home
- `/about-us/` — About Us
- `/products/` — Products
- `/blogs/` — Blog articles
- `/product-gallery/` — Product gallery
- `/contact-us/` — Contact

Edit `src/content.js` for the product, client, process, and blog content. Edit `src/App.jsx` and `src/App.css` for page components and styling. Original site images and videos are in `public/site-media/`.

`npm run build` creates a production build in `dist/`.
